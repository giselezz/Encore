# Encore

A concert journal iOS app for saving photos, memories, and details from live shows. 

## Problem
Concertgoers can have photos and personal notes scattered across different apps, making it difficult to revisit the full memory of a show. 

## Target User
A music lover who goes to concert regularly and wants to organise & revisit their concert memories. 

## Planned Features
- Create concert entries with an artist, venue, and date. 
- Attach photos and personal notes. 
- Browse past concerts by artist or year. 
- Save photos through a Share Extension. 
- Revisit memories through a Home Screen widget. 

## Architecture
SwiftUI Views → ViewModels → Use Cases → Repositories → Core Data. 

## Database
Core Data stores concert entries and their related memories.
